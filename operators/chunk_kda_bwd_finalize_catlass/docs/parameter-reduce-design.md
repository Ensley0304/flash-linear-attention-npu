# S9 参数梯度归约候选

当前每个 AIV 将 32 行、每行 128 个 FP32 的 dg 串行相加，得到 dt_bias 的局部梯度；每次 Add 后有 Vector 屏障。拟改为 16、8、4、2、1 行的五层树形归约，减少串行依赖和指令发射。只改这一项，逆向 scan、a_log 归约和跨 AIV 合并保持原样。

第一层把 dg 的前后各 16 行相加到已结束生命周期的 e 区（UB 32 KiB 起，使用 8 KiB）。后续在该区域原位折半，最后写入 partial[8:136]。保留 dg，供输出使用。该区后续归一化用作 term，会重新写入；不扩大 UB、不改变 DMA 或同步事件。

风险是 FP32 加法结合顺序变化。先普通和单核边界用例，再八配置两轮 A/B；稳定收益后原 20 case 七输出使用原 FP32 标杆、FP64 golden、CT 与附加策略验收。若不通过，撤销本项，不能放宽阈值。最终仍需全量验收。

收益只能由实测确认；即使通过也不能据此宣称达到 70% 目标。P5e 完整块路径完成验收或撤销后才实施。
