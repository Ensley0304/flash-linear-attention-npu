# P5b：S7 每块从8行增至16行（待试验）

前提：先结束P5的性能和七输出验收。每次仅修改S7，不叠加S9或rH优化。

S5结束后，e不再被读取。复用其16KiB，UB总量仍为188KiB。

| 区间（KiB，左闭右开） | S7用途 | 大小 |
| --- | --- | --- |
| 32～40 | kf，16×128 FP32 | 8KiB |
| 40～48 | delta，原位转成exp | 8KiB |
| 132～156 | 输出槽0：kn、qp、bp各8KiB | 24KiB |
| 156～180 | 输出槽1：kn、qp、bp各8KiB | 24KiB |
| 180～180.5 | center，128 FP32 | 0.5KiB |
| 180.5～181 | edge，128 FP32 | 0.5KiB |
| 185～188 | 已有mask、beta广播、diag广播 | 不变 |

两个band仍按1、0执行；每片AIV仍负责32行，每band两块，每块16行。

1. 等对应输出槽的MTE3结束，再改写该槽。先前aq/ak写回必须已排空。
2. k转成kf；q直接转到qp输出槽，不额外申请qf。
3. 对kn有效前缀计算center-g、乘ln2、原位Exp，再乘kf。
4. 加Vector屏障，保证kn已读完delta，才能用g-center覆盖delta。
5. 对qp/bp有效前缀计算正指数；bp仍先算kf×beta再乘指数，qp原位乘指数。无效后缀直接清零。
6. 同一输出槽的三块数据写回后发free。band完成后沿用原跨核ready；GM和L1布局不变。

负指数范围止于band末行；正指数范围从band首行延伸到整个chunk末尾。band0中第二片AIV的qp/bp仍须计算。

变更只减少循环和指令调用，不改变有效行的浮点运算顺序。重点检查：半块/尾块、band无有效行、delta原位覆盖、两个输出槽交替，以及center地址不与新输出槽重叠。

验收：六个边界冒烟每例20次；同设备八配置两轮交替A/B；稳定收益后原20case七输出；全部通过才能保留。原FP32局部矩阵乘、CT L1和附加精度策略不变。
