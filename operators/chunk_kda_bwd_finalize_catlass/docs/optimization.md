# 70% A5 吞吐目标的迭代记录

固定目标：B1/H96/T8192/K=V128/BF16，无norm和beta反向，主核加归约核不超过9604.066us。A5为历史6.7228465ms，当前不可复测，不宣称同环境A5对比。旧A2基线保持原分支和标签。

## 当前证据

- 初始完整候选：两轮msprof，每轮20次预热、20次采样，无附加反向21046.006us，仅beta反向21065.638us。Vector约55%，AIV Scalar约43%。八配置验收未完成。
- 完整6个多核冒烟通过，原case192的8K七输出通过CT L1和冻结附加策略。
- P1 beta批量广播：6个多核冒烟通过，8K case192七输出与初始候选逐位相同；原20case七输出全部通过。八配置两轮交替A/B平均降时7.33%，单轮单配置最小降时6.77%。8K无附加反向21061.379→19452.631us，P1保留。八配置使用旧性能缓存输入；初测使用case192输入，二者分别归档，不混作同一轮。

## 单项实验顺序

| 顺序 | 候选 | 根据与预期作用 | 精度或同步风险 |
| --- | --- | --- | --- |
| P1 | beta批量广播 | 去掉S3/S5/S7/S9逐行GetValue和Muls；减少标量指令 | 保持乘法顺序；广播槽不得覆盖 |
| P2 | 对角项、norm及db写回批量处理 | 去掉S9标量逐行访问和散写打包 | 对角Gather索引、尾行和布局 |
| P3 | 原位逆序scan | 每行一次Add，去掉每行复制suffix；保持串行加法次序 | 空片、最后一行和跨AIV suffix |
| P4 | suffix与partial分开发布 | AIV0收到suffix即开始scan，不再等待AIV1全部gate归约 | 独立ready标志、GM槽生命周期 |
| P4b | 定长元数据直接推导 | 热循环每个AIC/AIV目前逐项读取GM；定长可由chunk编号计算 | 多batch、尾块及uint64_t偏移；变长保留 |
| P4c | S7三角mask初始化一次、批量选择 | 每work的64次逐行Duplicate改为两次Select | 显式比较寄存器、UB185KiB常驻槽、尾行清零 |
| P4d | S0提前一个work | S0写relay[0,80)KiB，S9读取其他区域，重叠Cube与Vector | flag9移至下代S0之后，S2前仍等free；末次单独排空；加测单核回绕 |
| P5 | S7有效区按连续块处理 | 避免无效行指数及重复逐行mask分支 | 三角因果范围、指数溢出和尾块 |
| P5b | S7复用已结束的e，tile从8行增至16行 | e的16KiB在S5后空闲；减少循环、广播和通知次数，保留输出双buffer | 先重算scratch地址和消费边界，不覆盖beta/diag常驻槽 |
| P5c | S9参数梯度分层归约 | dt_bias的32次逐行Add改为树形归约，降低串行依赖 | FP32累加顺序改变，七输出精度不通过就撤销 |
| P5d | rH两片各算64行 | S1当前由末行owner独算128行；S9才消费，可借已有flag3→flag4保证两片写回可见 | 规划relay153KiB的512B；检查尾块、空片及Stage抓取；每行加法顺序保持 |
| P5e | 完整64行chunk编译期分支 | 由host校验过的rows决定路由，裁剪各Stage尾块判断；当前AIV Scalar占比仍高 | 独立完整块小case；保留混合尾块/变长通用分支，不套用已撤销的P4b |
| P5f | S9复用g/e，tile从8行增至16行 | 两组16行输入先完成缩放恢复，g随即复用为qf/kf；减少循环和指令启动 | 因子必须先全部消费，输入双buffer和逐行加法顺序保持 |
| P6 | 评估状态收缩转Cube | AIC已有h/dh，探索小块对角乘积替代Vector rH归约 | 归约次序改变；需逐Stage和原20case验证 |
| P7 | W2跨work提前S0 | 用S9时间准备下一work，隐藏部分Cube和搬入 | 先重新设计slot、credit、L1生命周期 |

每次只实现一项。先最小边界精度，再八配置两轮交替A/B；稳定收益后跑原20case、七输出，全部通过才保留。测试CPU缓存用reference源码hash、spec、seed作键；最终200case三轮fresh验收。未通过的候选保留证据并回退，不降低阈值。

空间处理：获用户明确授权后，仅清理perf-initial-8k及perf-p1-8k中的35个output_*.bin，释放5049141120字节；原始输入、精度输出和profiling均保留。后续多轮性能采集复用输出文件，不再每轮保存一份大张量。

P2 对角、norm和db批量处理：八配置两轮交替A/B均有收益，降时6.55%～9.87%；8K无附加反向19459.909→18184.937us。原20case七输出全部通过CT L1和冻结附加策略，保留P2。case192首轮host进程60秒超时，原因未确定；同一输入独立重试18.21秒正常退出，随后192/199完整精度通过。失败日志保留，没有放宽超时或精度阈值。证据见evidence/p2-*。

P3原位逆序scan已保留：六个边界冒烟及原20case七输出通过；两轮八配置平均降时2.89%，单轮最小2.27%。8K无附加反向18158.711→17613.720us。未改加法关联顺序、跨核事件及精度阈值。证据见evidence/p3-*。

P4 suffix/partial分开发布已保留：六个边界冒烟及原20case七输出通过；两轮八配置平均降时1.90%，单轮最小1.66%。8K无附加反向17666.728→17311.589us。证据见evidence/p4-*，未改变浮点运算顺序和精度阈值。

P4b定长元数据推导已撤销：六个冒烟通过，但两轮八配置平均慢0.44%，所有配置均无收益，性能门禁未通过，因此没有进入原20case验收。恢复P4；报告与失败候选补丁见evidence/p4b-*。

P4c批量三角mask已保留：六个边界冒烟及原20case七输出通过；两轮八配置平均降时4.98%。8K无附加反向17314.034→16424.155us。证据见evidence/p4c-*；只改变掩码执行方式，原精度条件不变。
