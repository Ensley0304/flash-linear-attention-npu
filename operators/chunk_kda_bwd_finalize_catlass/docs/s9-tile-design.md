# S9扩大tile（待试验）

先结束rH分担验收，再单独修改S9。保持逐行乘加顺序、逆序scan和参数归约顺序；每块从8行增至16行。

| UB区间（KiB，左闭右开） | 使用顺序 |
| --- | --- |
| 16～32，原g | 先原位生成32行缩放因子并恢复两组输入；全部因子读完后，分作qf/kf各8KiB |
| 32～48，原e | S5后不再需要；作term/product各8KiB |
| 132～156 | 输入槽0：localQ/left/right各8KiB |
| 156～180 | 输入槽1：localQ/left/right各8KiB |
| 180～181 | 行归约临时量 |
| 182～182.5 | norm广播16行 |
| 184起 | 远端partial，保留544B |
| 185～188 | mask、beta、diag常驻量不变 |

执行顺序：

1. 排空S7输出槽。先做状态修正，临时量放132KiB起，结束后通过V→MTE2事件释放给输入DMA。
2. 搬入两组16行输入，同时在g区计算全部缩放因子；尾行先清零，避免无效指数溢出。
3. 等各组MTE2就绪，按原顺序恢复localQ、left、right（乘、乘、除）。两组都完成并加Vector屏障后，才能覆盖g区。
4. 用g区作qf/kf，分两块完成dq/dk/dg/db合并；beta/diag广播偏移改为tile×16×8。
5. scan和gate参数归约保留原次序。norm与输出分两块16行，输出双槽各4KiB，尾块长度正确裁剪。

两组输入物理分离，事件独立。不得在第二组恢复因子前将g覆盖为qf/kf；不得在输入最后一次读取前复用132～180KiB作为gateProduct或输出。

验收沿用六个边界冒烟、八配置两轮交替A/B、原20case七输出；全部通过再保留。若恢复因子和合并重排使精度变化，定位并回退，不放宽阈值。
